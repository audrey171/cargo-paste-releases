# Cargo Paste for Mac

Cargo Paste keeps up to five copied items within reach, preserving text formatting, images and GIFs.

Download the latest signed and notarized app from [Releases](https://github.com/audrey171/cargo-paste-releases/releases/latest), or install with Homebrew:

```sh
brew install --cask audrey171/tap/cargo-paste
```

Requires macOS Sonoma 14 or later. Supports Apple Silicon and Intel Macs.
For hold-Command-V across apps, enable Cargo Paste in System Settings → Privacy & Security → Accessibility.

Website: https://cargopaste.com/
Homebrew package: https://github.com/audrey171/homebrew-tap
