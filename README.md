# Cargo Paste for Mac

Cargo Paste keeps five copied items within reach, with original formatting, images and GIFs.

Website: https://cargopaste.com/

Signed macOS downloads will appear in this repository’s Releases. The first release is being prepared; Homebrew installation is not live yet.

This repository hosts app downloads. Homebrew packaging lives at https://github.com/audrey171/homebrew-tap.
